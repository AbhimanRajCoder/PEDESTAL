# Pedestal | The Gamified Financial Ecosystem

![Pedestal App](/app.png)

Pedestal is a premium, high-conversion fintech landing page designed for India's New Money Generation. It transforms traditional financial education into an immersive, addictive, and gamified experience.

## 🚀 Key Features

### 1. Immersive Gamification
- **Live XP Engine**: A real-time experience point tracker that rewards users for exploring the page and completing challenges.
- **Sorting Hat Onboarding**: Personalized risk-profiling that adapts the learning path to the user's goals.
- **Salary Survivor RPG**: A conceptual approach to teaching budgeting and wealth building through game mechanics.
- **Global Leaderboards**: Interactive rank-up animations that simulate a competitive social environment.

### 2. Interactive Learning "Arcade"
- **Market Simulator**: A risk-free paper trading interface with real-time chart animations and "Buy/Sell" RPG-style feedback.
- **Financial Jigsaw**: A desktop-exclusive challenge where users assemble pieces to reveal and learn complex financial concepts.
- **60-Second Sprints**: Shuffled micro-lessons presented as high-fidelity flip cards with +XP rewards.

### 3. State-of-the-Art Visuals & UI
- **Luxury Loader**: A multi-stage, high-fidelity entry animation featuring a "card deal" sequence. It is session-aware, ensuring it only plays once per visit.
- **Interactive Glow Layer**: A subtle, mouse-following neon glow that creates a deep, immersive background depth.
- **Hero Parallax**: Advanced 3D tilt effects on device mockups and floating UI elements that respond to mouse movement.
- **Lo-Fi Atmosphere**: Integrated background music with custom, glassmorphism-styled audio controls.

## 🛠 Tech Stack
- **Structure**: Semantic HTML5
- **Styling**: Vanilla CSS3 + Tailwind CSS (Core Framework)
- **Animation**: GSAP (GreenSock Animation Platform) + ScrollTrigger
- **Icons**: Lucide Icons
- **Logic**: Vanilla JavaScript (ES6+)
- **State Management**: LocalStorage (Persistent XP/Streaks) & SessionStorage (Loader persistence)

## 📂 Project Structure
- `index.html`: The main landing experience.
- `waitlist.html`: High-conversion lead capture form.
- `style.css`: Custom design tokens, glassmorphism, and complex animations.
- `script.js`: Core engine (XP tracking, GSAP reveals, Interactive Glow).
- `jigsaw.js`: Logic for the canvas-based interactive puzzle.
- `app.png` / `logo.png`: Brand assets.
- `bgmusic.mp3`: Atmospheric background audio.
